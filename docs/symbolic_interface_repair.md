# Symbolic interface repair

- `smooth-nau` uses tanh features and a whole deterministic-action derivative bound, including the quadratic projection and output squash. Historical LeakyReLU and hard-clamped actors remain uncertified.
- SINDy fits aligned state/action/increment tuples; its Torch bridge uses the fitted exponent matrix. The LQR reference comes from identified matrices and task costs, using SciPy's Riccati solver: https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.solve_discrete_are.html.
- JC uses the full squared Frobenius difference of action-valued Jacobians. Reference gradients and critic penalties are detached. Boundary errors are measured at the specified point; the replay-count PAC correction and parameter-to-return overlays are removed.
- `tests/test_symbolic_alignment.py`: 12 focused tests; the existing 100-update smoke test and a short OOD-evaluation CLI run also pass. These checks validate implementation, not a performance gain.
